# Hamzah Marie Portfolio

A responsive personal software engineering portfolio built with semantic HTML, modern CSS, and vanilla JavaScript.

The site highlights my experience, technical skills, featured projects, and contact information.

## Live Site

[View Live Portfolio](https://starlit-swan-32a6ca.netlify.app/)

## Features

* Responsive mobile-first design
* Semantic HTML structure
* Flexbox and CSS Grid layouts
* Mobile hamburger navigation
* Smooth scrolling between sections
* Scroll-based reveal animations
* Experience and skills sections
* Featured project links
* Resume download
* GitHub, LinkedIn, and email contact links

## Technologies

* HTML
* CSS
* JavaScript

## Run Locally

Clone the repository:

```bash
git clone https://github.com/HamzahM03/CSC-436-Project1.git
```

Navigate into the project folder:

```bash
cd CSC-436-Project1
```

Open `index.html` in your browser.

No package installation or build step is required.
